# itsdrdan.github.io

Root of itsdrdan.github.io. Forwards visitors (and any unknown address) to [Dr. Dan’s Chemistry Study Hub](https://itsdrdan.github.io/games/).

Any other address that GitHub can't find is caught by `404.html`, which fixes the capitalization of known repos (for example `/mcat` → `/MCAT/`, `/GasLaws` → `/gaslaws/`) and otherwise sends visitors to the Chemistry Study Hub.
